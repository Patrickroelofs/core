# Footer

Closing footer where the name is the email link. A compound component: `Footer`, `Footer.Meet` and `Footer.Bar`.

- `Footer.Meet` is an `<a>` (or `render={…}`) with `first` (thin), `last` (black) and `email`. They sit apart at rest; on hover or focus they pull together around a coral pill that shows the email. Links to `mailto:email` unless `href` is set.
- `Footer.Bar` is the optional strip underneath, e.g. copyright and location.

```tsx
import { Footer } from '@core/ui/footer/footer'

<Footer>
  <Footer.Meet first="Ada" last="Lovelace" email="ada@example.com" />
  <Footer.Bar>© 2026</Footer.Bar>
</Footer>
```

## Accessibility

- Rendered as `<footer>` (a `contentinfo` landmark when top-level). The link's accessible name is "First Last, email address"; the visual parts are `aria-hidden`.
- Keyboard focus triggers the same motion as hover and adds an underline.
- Motion is disabled with reduced motion.

## Don't

- Don't pass `className`.
- Don't use `Footer.Meet` for a link that doesn't go to a person; the pill promises an email.
