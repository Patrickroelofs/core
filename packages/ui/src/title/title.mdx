# Title

Heading on the Utopia fluid type scale (https://utopia.fyi). Sizes interpolate between viewport widths via `clamp()`, so no breakpoints are needed. Renders an `<h2>`; use the `render` prop for another level.

```tsx
import { Title } from '@core/ui/title/title'

<Title size="5" render={<h1 />}>Hello</Title>
```

<Canvas of={Stories.Default} />
<Controls of={Stories.Default} />

## Sizes

`3`, `4` (default), `5`, `6` map to fluid steps 3–6.

<Canvas of={Stories.Sizes} />

## Accessibility

Pick the element with `render` so the heading outline stays correct; size is visual only.

## Don't

- Don't pass `className`; styling comes from the recipe.
- Don't choose the size to get the heading level, or vice versa.
