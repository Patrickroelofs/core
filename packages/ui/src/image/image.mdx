# Image

Fixed-ratio image that fills its container's width. With a `src` it renders an `<img>` (`object-fit: cover`); without one it renders a striped placeholder showing `label`.

```tsx
import { Image } from '@core/ui/image/image'

<Image src="/shiftboard.png" alt="Shiftboard dashboard" ratio="16/9" />
<Image label="shiftboard: dashboard" tone="azure" />
```

## Placeholder tone

`light` (default), `dark`, `azure`, `coral`. Ignored when `src` is set.

<Canvas of={ImageStories.Tones} />

## Accessibility

- Always give a real `src` a meaningful `alt` (use `alt=""` only for decoration).
- The placeholder is a plain `<div>` with visible `label` text and ignores `alt`.

## Don't

- Don't pass `className`; styling comes from the recipe.
- Don't use the placeholder in production content; it marks a missing image.
