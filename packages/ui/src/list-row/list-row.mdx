# ListRow

Hairline-separated row for CV entries, posts and credits. A compound component: `ListRow`, `ListRow.Lead`, `ListRow.Body` and `ListRow.Meta`.

- `Lead`: mono column, usually a date range. Optional; without it the body takes the first column.
- `Body`: put `Title as="span"` inside (bold part, then light detail).
- `Meta`: trailing small text, usually a `Label`.
- `render={<a href="…" />}` makes a link row that turns coral on hover and focus.

```tsx
import { ListRow } from '@core/ui/list-row/list-row'

<ListRow>
  <ListRow.Lead>2020 — 2024</ListRow.Lead>
  <ListRow.Body>
    <Title as="span" size="sm" weight="bold">Founding designer</Title>
    <Title as="span" size="sm">{' · Fieldkit'}</Title>
  </ListRow.Body>
  <ListRow.Meta><Label>Remote</Label></ListRow.Meta>
</ListRow>
```

## Accessibility

- A link row is a real `<a>`; the whole row is the target and shows a focus ring.
- Wrap rows in `<ul>`/`<li>` (via `render`) when they form a list.

## Don't

- Don't pass `className`.
- Don't put interactive elements inside a link row.
- Don't rely on colour alone to show a row is a link.
