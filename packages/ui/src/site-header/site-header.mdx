# SiteHeader

Sticky top bar. A compound component: `SiteHeader`, `SiteHeader.Monogram` and `SiteHeader.Rule`. Anything else inside (usually a `NavigationMenu`) is laid out after them.

- `SiteHeader.Monogram` shows the full name. Once the page scrolls (more than a few pixels) the header gets `data-collapsed` and each word's reel rolls down to its initial and a coral dot ("P.R."); hover or focus rolls it open again. Pass the full `name`; the first word is light, the others black.
- `SiteHeader.Rule` is a hairline filling the gap between monogram and nav. It fills from the left with the page's scroll progress (0% at the top, 100% at the bottom), where a 👍 pops out of its end.

- The header publishes `--site-header-height` on `<html>`, so other sticky elements (e.g. `SectionNav`) can sit under it. While a `SectionNav` is docked the header's fade-out is handed to that bar.

The header sticks to the top of the viewport, so render it as a direct child of a tall container (usually `<body>`). Its backdrop spans the full width, while its content lines up with a centred 1400px column (`maxW: '[1400px]', mx: 'auto', p: 'gutter'`).

```tsx
import { SiteHeader } from '@core/ui/site-header/site-header'

<SiteHeader>
  <SiteHeader.Monogram href="/" name="Patrick Roelofs" />
  <SiteHeader.Rule />
  <NavigationMenu>…</NavigationMenu>
</SiteHeader>
```

## Accessibility

- Rendered as a sticky `<header>` (a `banner` landmark when top-level).
- The monogram is a link labelled with the full `name`; its letters are hidden from assistive tech so it never reads as "P.R.". Focus rolls it over like hover.
- The slot and the rule are disabled with reduced motion.

## Don't

- Don't pass `className`.
- Don't pass a single-word `name`; there would be nothing to abbreviate.
- Don't rely on the animation to show the name; it is decoration, the label carries it.
