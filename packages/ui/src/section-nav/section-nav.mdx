# SectionNav

Sticky "on this page" bar for long pages (About, case studies). A compound component: `SectionNav` and `SectionNav.Link`. Each link points at a section's `#id`; the bar watches the scroll position and slides a navy pill to the link of the section in view.

- A section becomes active once its top passes `offset` px (default 40) below the bar. At the very bottom of the page the last link wins. Above the first section no link is active and the pill is hidden; it fades in on the first one, then slides and resizes between links.
- Clicking a link is a plain in-page anchor jump; the browser scrolls and updates the hash (so Back returns to the previous section). `@core/ui/styles.css` makes it smooth on any page with a `SectionNav` (`html:has([data-section-nav]) { scroll-behavior: smooth }`) and gives every `[id]` there a `scroll-margin-top` that clears the header and the bar, so sections land 16px below it. The pill goes straight to the clicked link and stays there for the whole scroll instead of stepping through every link on the way.
- It sticks right under the site header at `var(--site-header-height)`, which `SiteHeader` publishes, and follows it if the header grows (e.g. the mobile menu opens).
- Once docked (`data-docked`) the bar takes over the header's blurred backdrop: one backdrop runs from the top of the header to below the bar and fades out there, so the two read as one surface with no seam (two stacked `backdrop-filter` layers each blur only what's behind them and leave a visible line). Before docking it is an opaque bar with a hairline rule.
- It publishes `--section-nav-height`, so things that stick below it (section labels) can use `top: calc(var(--site-header-height, 0px) + var(--section-nav-height, 0px) + 16px)`.
- When the links don't fit (phones) the row scrolls sideways, the active link is kept centred and the edges fade.

```tsx
import { SectionNav } from '@core/ui/section-nav/section-nav'

<SectionNav>
  <SectionNav.Link href="#story" number="01">Story</SectionNav.Link>
  <SectionNav.Link href="#experience" number="02">Experience</SectionNav.Link>
</SectionNav>
<section id="story">…</section>
<section id="experience">…</section>
```

## Accessibility

- A `<nav>` landmark labelled "On this page" (override with `aria-label`).
- The active link has `aria-current="location"`.
- Links are real anchors: scrolling to a section needs no JavaScript, and modifier-clicks open normally.
- With reduced motion, scrolling jumps and the pill and bar move without animating.

## Don't

- Don't pass `className`.
- Don't link to ids that aren't on the page; those links never become active.
- Don't use it for page-to-page navigation; that is `NavigationMenu`.
