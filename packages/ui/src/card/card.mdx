# Card

Work card: `Image` slot, heavy title, year, description and role tag. A compound component; compose only the parts you need.

- `Card`: root surface, a `<div>`. Use `render={<a href="…" />}` for a link card that lifts 4px and turns its title `black` on hover.
- Image: use the `Image` component (`@core/ui/image/image`) as the first child; it has `ratio` and placeholder `tone` props.
- `Card.Media` + `Card.Reveal`: wrap the `Image` in `Card.Media` and add a `Card.Reveal` for the hover reveal (below).
- `Card.Body`: vertical stack for the text parts.
- `Card.Footer`: row for `Tag`s on the left and a `<time>` pushed to the right edge; wraps on narrow cards.
- Text and tags: use the existing `Title` (`as="h3"`), `Typography`, `Tag` and `Label` (`render={<time dateTime="…" />}`, for the date) directly inside the body and footer. Headings inside a card are restyled to the card title look (30px, extrabold, black on link hover).

```tsx
import { Card } from '@core/ui/card/card'
import { Image } from '@core/ui/image/image'
import { Label } from '@core/ui/label/label'
import { Tag } from '@core/ui/tag/tag'
import { Title } from '@core/ui/title/title'
import { Typography } from '@core/ui/typography/typography'

<Card render={<a href="/work/shiftboard" />}>
  <Image src="…" alt="Shiftboard dashboard" />
  <Card.Body>
    <Title as="h3">Shiftboard</Title>
    <Typography>Scheduling for night-shift nurses.</Typography>
    <Card.Footer>
      <Tag tone="coral" size="sm">Lead designer</Tag>
      <Label size="xs" render={<time dateTime="2024" />}>2024–26</Label>
    </Card.Footer>
  </Card.Body>
</Card>
```

On a link card, a tone panel (`tone`: `coral`, `azure`, `plum`, `navy`) wipes up over the image with the CTA text and a ↗. It also shows on keyboard focus. Static cards never show it.

## Accessibility

- A link card is one `<a>`; its accessible name is the whole text content, so keep the title first.
- Always give `<img>` meaningful `alt`. The placeholder label is visible text, not an image description.
- `Card.Reveal` is `aria-hidden`; the link's name comes from the card text, so don't put information only in the CTA.
- Hover motion is disabled under `prefers-reduced-motion`.

## Don't

- Don't pass `className`; styling comes from the recipe.
- Don't put interactive elements (buttons, links) inside a link card.
- Don't skip heading levels: set `Title`'s `as` to fit the page outline.
