# Tile

Rounded coloured panel for bento grids. Sets `data-surface` from `tone`, so `ListRow`, `Label` and other semantic-token components inside follow the panel colour. Renders a `<div>`; use `render` for a link.

```tsx
import { Tile } from '@core/ui/tile/tile'

<Tile tone="plum">
  <Tile.Label>Toolkit</Tile.Label>
  …
</Tile>
```

## Tones

`navy` (default), `plum`, `azure`, `coral`, `snow`.

## Link tile

Pass `render={<a href="…" />}`. The tile flips to navy on hover and gets a focus ring.

<Canvas of={Stories.Link} />

## Layout

`justify` is `between` (default, label top and content bottom) or `start`. `Tile.Label` is the small caption.

## Bubble

`shape="bubble"` rounds three corners and leaves the bottom-left tight, like a speech bubble. Use it for quotes and greetings, with the speaker's caption underneath.

<Canvas of={Stories.Bubble} />

## Accessibility

Navy on coral is 4.2:1, the best the palette allows; keep coral tile text large. A link tile needs meaningful link text, not just a label.

## Don't

- Don't pass `className`; styling comes from the recipe.
- Don't set the tile colour with your own background; use `tone`.
