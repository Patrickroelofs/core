# LabeledSection

Hairline-topped page section with a sticky label column beside the content. A compound component: `LabeledSection`, `LabeledSection.Label` and `LabeledSection.Content`.

- `LabeledSection`: requires `id`, the anchor for `SectionNav.Link href="#id"`.
- `LabeledSection.Label`: children are the `h2` title; optional `hint`. Sticks below the SiteHeader and a docked SectionNav on `md` and up.
- `LabeledSection.Content`: the right column.

```tsx
import { LabeledSection } from '@core/ui/labeled-section/labeled-section'

<LabeledSection id="experience">
  <LabeledSection.Label hint="Twelve years, five chapters">Experience</LabeledSection.Label>
  <LabeledSection.Content>…</LabeledSection.Content>
</LabeledSection>
```

## Accessibility

- The `<section>` is labelled by the `LabeledSection.Label` title, so always render a `Label`.

## Don't

- Don't pass `className`.
- Don't omit `LabeledSection.Label`; the region would have no name.
- Don't nest a `LabeledSection` inside another.
