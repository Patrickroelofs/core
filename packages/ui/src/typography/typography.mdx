# Typography

Body text on the Utopia fluid type scale. Renders a `<p>`; use `render` for other elements.

```tsx
import { Typography } from '@core/ui/typography/typography'

<Typography size="lg">Intro copy</Typography>
```

<Canvas of={Stories.Default} />
<Controls of={Stories.Default} />

## Sizes

`xs`, `sm`, `md` (default), `lg`, `xl` map to fluid steps -2 to 2.

<Canvas of={Stories.Sizes} />

## Accessibility

Sizes are fluid rem-based, so text respects user font settings.

## Don't

- Don't pass `className`; styling comes from the recipe.
- Don't use it for headings (`Title`) or form labels (`Label`).
