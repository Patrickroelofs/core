# Grid

Layout container with two modes and a fluid gap. A compound component: `Grid` and `Grid.Item`.

- `layout="bento"` (default): 12-column grid from `md` up, a single column below. `Grid.Item` takes `span` (1–12) and `rowSpan` (1–3), applied from `md` up.
- `layout="flex"`: wrapping row; items grow evenly from a 16rem basis. `span` and `rowSpan` have no effect.
- `gap`: fluid space token that scales with the viewport: `xs`, `s`, `s-m`, `m` (default), `m-l`, `l`, `xl`.
- `render` on both parts swaps the element, e.g. `<ul>` / `<li>`.

```tsx
import { Grid } from '@core/ui/grid/grid'

<Grid gap="m-l">
  <Grid.Item span={8} rowSpan={2}>…</Grid.Item>
  <Grid.Item span={4}>…</Grid.Item>
  <Grid.Item span={4}>…</Grid.Item>
</Grid>
```

## Accessibility

- Source order is reading and tab order; spans never reorder content.
- For a list of items use `render={<ul />}` and `render={<li />}`.

## Don't

- Don't pass `className`; styling comes from the recipe.
- Don't use `span` in a `flex` grid.
- Don't make spans in a row add up past 12; they wrap onto the next row.
