# Tag

Pill label for roles, clients and tools. Static by default (a `<span>`); pass `pressed`, `defaultPressed`, `onPressedChange` or `onClick` and it becomes a toggleable filter chip built on Base UI's `Toggle` (a `<button>` with `aria-pressed`).

```tsx
import { Tag } from '@core/ui/tag/tag'

<Tag tone="coral" size="sm">Lead designer</Tag>
<Tag appearance="outline" pressed={active} onPressedChange={setActive}>Product</Tag>
```

## Tones

`coral`, `azure`, `plum`, `navy` (default), `snow`.

<Canvas of={TagStories.Tones} />

## Appearances

`solid` (default), `outline`, `soft`. Outline and soft fill with the tone when pressed or hovered (interactive tags only). Use outline with snow on azure tiles; soft on plum tiles.

<Canvas of={TagStories.Soft} />

## Filter chips

`TagProps` is a union: toggle props (`pressed`, `defaultPressed`, `onPressedChange`) select the interactive variant, and a static tag rejects them at the type level. For a single-select group, control `pressed` from your own state.

<Canvas of={TagStories.FilterChips} />

## Accessibility

Interactive tags are real buttons with `aria-pressed` and a visible focus ring. Static tags are plain text.

## Don't

- Don't pass `className`; styling comes from the recipe.
- Don't rely on tone alone to convey meaning.
