# HeroIntro

Intro sentence for the top of a page, with inline photo pills. A compound component: `HeroIntro`, `HeroIntro.Phrase`, `HeroIntro.Word` and `HeroIntro.Pill`.

- `HeroIntro` is an `<h1>`; write the sentence as text with `Phrase`s in it.
- A `Phrase` wraps a `Word` (thin, turns black when active) and a `Pill` (a pill-shaped photo slot whose image overflows into a 1/1 circle when active, without moving the text).
- A `Pill` holds one `Image`.

```tsx
import { HeroIntro } from '@core/ui/hero-intro/hero-intro'
import { Image } from '@core/ui/image/image'

<HeroIntro>
  Hi, I’m{' '}
  <HeroIntro.Phrase>
    <HeroIntro.Word>Patrick</HeroIntro.Word>{' '}
    <HeroIntro.Pill><Image src="/me.jpg" /></HeroIntro.Pill>
  </HeroIntro.Phrase>
  .
</HeroIntro>
```

## Accessibility

- The sentence is real heading text; pills are `aria-hidden` and carry no information.
- The overflow is triggered by hover and focus within a phrase, and is disabled with reduced motion.

## Don't

- Don't pass `className`.
- Don't put anything in a `Pill` that is needed to understand the sentence.
- Don't use more than one `HeroIntro` per page.
