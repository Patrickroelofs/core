# Colors

Primitive color tokens from `@core/theme`.

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(160px, 1fr))', gap: 16 }}>
  {[
    ['snow', '#f0f0f0'],
    ['plum', '#50216a'],
    ['navy', '#192036'],
    ['azure', '#0177bb'],
    ['coral', '#d65b5c'],
  ].map(([name, hex]) => (
    <div key={name} style={{ border: '1px solid #d4d4d8', borderRadius: 8, overflow: 'hidden' }}>
      <div style={{ height: 96, background: `var(--colors-${name})` }} />
      <div style={{ padding: 8, fontFamily: 'system-ui, sans-serif', fontSize: 14 }}>
        <strong>{name}</strong>
        <br />
        <code>{hex}</code>
      </div>
    </div>
  ))}
</div>

## Semantic

Intent-based tokens that reference the primitives above.

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(160px, 1fr))', gap: 16 }}>
  {[
    'bg.canvas', 'bg.inverse', 'fg.default', 'border.default',
    'action.primary', 'action.primaryHover', 'accent.brand', 'accent.info', 'accent.highlight', 'focusRing',
  ].map((name) => (
    <div key={name} style={{ border: '1px solid #d4d4d8', borderRadius: 8, overflow: 'hidden' }}>
      <div style={{ height: 64, background: `var(--colors-${name.replace('.', '-')})` }} />
      <div style={{ padding: 8, fontFamily: 'system-ui, sans-serif', fontSize: 14 }}>
        <code>{name}</code>
      </div>
    </div>
  ))}
</div>

## Surfaces

Set `data-surface="snow | plum | azure | coral | navy"` on any element. It sets the background and repoints the semantic color variables (`fg.default`, `action.primary`, `border.default`, `focusRing`, ...), so components inside pick readable colors on their own. Nesting works.

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(160px, 1fr))', gap: 16 }}>
  {['snow', 'plum', 'azure', 'coral', 'navy'].map((s) => (
    <div key={s} data-surface={s} style={{ padding: 16, borderRadius: 8, fontFamily: 'system-ui, sans-serif' }}>
      <strong style={{ color: 'inherit' }}>{s}</strong>
      <p style={{ color: 'inherit', margin: '8px 0 0', borderTop: '1px solid var(--colors-border-default)', paddingTop: 8 }}>Readable text</p>
    </div>
  ))}
</div>
